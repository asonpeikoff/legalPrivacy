User agent

The user agent is the line every browser sends that says what browser and system it is. Noise that claims a different browser than yours can stand out. Pick how the plain-HTTP noise sets it.
Advice
  • Your own browser's user agent means the noise looks like you, same as your real traffic. This is what we recommend.
  • Random changes the browser the noise claims to be every hour or day, drawn from the library below. Good if you want noise to look like a mix of visitors; it adds a second browser on your connection.
  • One library entry is a single fixed browser. Only pick this for a specific reason, since one fixed browser is an easy pattern.

What this does

noisyCricket sends believable random searches, page visits and DNS lookups in the background so that bulk analysis of any one person's real browsing is less useful. Every request is shown in Activity; everything the app and Tor say is in Live Log.

Tor (optional). Off by default. With Tor on, noisyCricket can visit .onion sites (darknet noise) through its own private Tor, which it downloads, verifies and starts for you. Routing ordinary clearnet noise through Tor is a separate switch, off by default, and not recommended.

Community relay. Never an exit node. See cricket relay gen in the README.

The dashboard listens only on this computer (127.0.0.1) and requires a one-time token in its address.
